Full reference for all 13 top-level `horton` commands. Every command also
accepts the three [global flags](/cli/#global-flags) — `--json`, `--host`,
`--api-key` — not repeated below.

Flags map to query parameters by dash→underscore (`--changed-since` becomes
`changed_since`); only flags you actually pass are sent, so server defaults
apply otherwise. List commands print a page of results as a table and,
unless noted, the next cursor to stderr — see [the cursor
footer](/cli/#the-stderr-cursor-footer).

## `login`

```
horton login [--with-token] [--host <host>]
```

Prompts for an API key (or reads it from stdin with `--with-token`),
validates it with an authenticated `GET /versions`, then saves the key and
host to `~/.config/horton/config.json`.

| Flag | Description |
| --- | --- |
| `--with-token` | Read the key from stdin without an interactive prompt |

```bash
horton login --host https://app.pglantern.com
```

## `logout`

```
horton logout
```

Deletes `~/.config/horton/config.json`. No arguments, no endpoint call.

```bash
horton logout
```

## `lists`

```
horton lists
```

Maps to `GET /lists`. Lists the mailing lists in the archive — name,
active status, description. No arguments or flags; not paginated.

```bash
horton lists
```

## `messages`

```
horton messages [flags]
```

Maps to `GET /messages`. Browses archived messages.

| Flag | Description |
| --- | --- |
| `--list` | Restrict to one mailing list by name |
| `--from` | ISO-8601 lower bound on `sent_at` |
| `--to` | ISO-8601 upper bound on `sent_at` |
| `--dir` | Sort direction: `asc` \| `desc` |
| `--limit` | Page size (server default 25, max 100) |
| `--after` | Page cursor |
| `--before` | Page cursor |

```bash
horton messages --list pgsql-hackers --limit 10
```

All `messages` subcommands take a raw `Message-Id` exactly as tables print
it (a wrapping `<>` is fine) — see [Message-Ids](/concepts/message-ids/).

### `messages get <message-id>`

Maps to `GET /messages/{message_id}`. Shows one message in full: headers,
thread id, attachments, and body text.

```bash
horton messages get '<20240311142203.GA12345@example.com>'
```

### `messages thread <message-id>`

Maps to `GET /messages/{message_id}/thread`. Shows every message in the
thread that contains the given message, as a table.

```bash
horton messages thread '<20240311142203.GA12345@example.com>'
```

### `messages commits <message-id>`

Maps to `GET /messages/{message_id}/commits`. Shows the commit groups that
landed from the message's thread. Prints `no commits landed from this
thread` on stderr if none did.

```bash
horton messages commits '<20240311142203.GA12345@example.com>'
```

### `messages refs <message-id>`

Maps to `GET /messages/{message_id}/refs`. Shows references extracted from
the message — shas, paths, CVEs — and, where resolvable, the sha they
resolve to.

```bash
horton messages refs '<20240311142203.GA12345@example.com>'
```

## `search`

```
horton search <query>... [flags]
```

Maps to `GET /search`. Full-text search over messages; all positional
words are joined with spaces into the `q` parameter.

| Flag | Description |
| --- | --- |
| `--sort` | Sort order: `relevance` (default) or `sent_at` |
| `--sender` | Substring match on sender email or name |
| `--committed` | Only threads with a landed commit |
| `--path` | Threads whose landed commit or patch touches this path prefix |
| `--major` | Threads that landed a commit first shipped in this major (`16`, `9.6`, `master`) |
| `--from` | ISO-8601 lower bound on `sent_at` |
| `--to` | ISO-8601 upper bound on `sent_at` |
| `--limit` | Page size (server default 25, max 100) |
| `--after` | Page cursor |
| `--before` | Page cursor |

```bash
horton search vacuum full --committed --major 17
```

## `commits`

```
horton commits [flags]
```

Maps to `GET /commits`. Browses Postgres commits linked to the archive.

| Flag | Description |
| --- | --- |
| `--path` | Commits touching files under this path prefix |
| `--author` | Substring match on author name or email |
| `--major` | Commits first shipped in this major (`16`, `9.6`, `master`) |
| `--from` | ISO-8601 lower bound on `committed_at` |
| `--to` | ISO-8601 upper bound on `committed_at` |
| `--limit` | Page size (server default 25, max 100) |
| `--after` | Page cursor |
| `--before` | Page cursor |

```bash
horton commits --path src/backend/access/ --major 16
```

### `commits get <sha>`

Maps to `GET /commits/{sha}`. Shows one commit in full — author,
committer, release containment, commit message, and changed files. Takes
the full 40-hex sha.

```bash
horton commits get a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2
```

### `commits thread <sha>`

Maps to `GET /commits/{sha}/thread`. Shows the mailing-list discussion
behind a commit — every archived thread that references it, plus any
unresolved references printed to stderr.

```bash
horton commits thread a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2
```

## `senders`

```
horton senders [flags]
```

Maps to `GET /senders`. Browses people who have posted to the lists.

| Flag | Description |
| --- | --- |
| `--q` | Substring match on email or display name |
| `--sort` | Sort key: `messages` \| `first` \| `last` |
| `--dir` | Sort direction: `asc` \| `desc` |
| `--limit` | Page size (server default 25, max 100) |
| `--after` | Page cursor |
| `--before` | Page cursor |

```bash
horton senders --sort messages --dir desc
```

### `senders get <id>`

Maps to `GET /senders/{id}`. Shows one sender's stats and recent messages.
`<id>` is the integer sender id (from the `ID` column of `horton
senders`).

```bash
horton senders get 42
```

## `threads`

```
horton threads [flags]
```

Maps to `GET /threads`. Browses discussion threads across the lists,
newest activity first.

| Flag | Description |
| --- | --- |
| `--q` | Substring on subject, or full-text over member messages |
| `--from` | Only threads active on/after this date (ISO-8601) |
| `--to` | Only threads active on/before this date (ISO-8601) |
| `--limit` | Page size (server default 25, max 100) |
| `--after` | Page cursor |
| `--before` | Page cursor |

```bash
horton threads --q vacuum --from 2024-01-01
```

## `attachments`

```
horton attachments [flags]
```

Maps to `GET /attachments`. Browses message attachments.

| Flag | Description |
| --- | --- |
| `--limit` | Page size (server default 25, max 100) |
| `--after` | Page cursor |
| `--before` | Page cursor |

```bash
horton attachments
```

### `attachments get <id>`

Maps to `GET /attachments/{id}`. Shows one attachment's metadata —
filename, content type, size, whether it's a patch, and its message id.
`<id>` is the integer attachment id.

```bash
horton attachments get 1234
```

### `attachments patch <id>`

Maps to `GET /attachments/{id}/patch`. Shows the parsed patch summary for
a patch attachment — format, patch series/sequence if detected, subject,
and per-file add/delete counts.

```bash
horton attachments patch 1234
```

## `versions`

```
horton versions
```

Maps to `GET /versions`. Lists Postgres major versions and their releases
— major, release date, EOL date, latest tag. No arguments or flags; not
paginated.

```bash
horton versions
```

### `versions gucs <major>`

Maps to `GET /versions/{major}/gucs`. Without `--changed-since`, shows the
full GUC catalog for that major. With it, shows the diff against the base
major instead: added, removed, default-changed, and context-changed GUCs.
`<major>` is `16`, `9.6`, `master`, etc.

| Flag | Description |
| --- | --- |
| `--changed-since` | Diff against this base major (`16`, `9.6`, `master`) |

```bash
horton versions gucs 17
horton versions gucs 17 --changed-since 16
```

## `activity`

```
horton activity <path> [flags]
```

Maps to `GET /source/activity`. Merged commit and discussion activity for
a source-tree path — `<path>` is sent as the `path` query parameter.

| Flag | Description |
| --- | --- |
| `--major` | Narrow commits to this major's containment (`16`, `9.6`, `master`) |
| `--limit` | Page size (server default 25, max 100) |
| `--after` | Page cursor |
| `--before` | Page cursor |

```bash
horton activity src/backend/access/ --major 16
```

## `imports`

```
horton imports [flags]
```

Maps to `GET /imports`. Shows mbox files imported into the archive —
filename, size, import timestamp.

| Flag | Description |
| --- | --- |
| `--list` | Mailing list name (server default `pgsql-hackers`) |

```bash
horton imports --list pgsql-hackers
```

## `api`

```
horton api <path> [--param key=value]...
```

Sends a raw `GET` to any `/api/v1` path and prints the JSON response —
the escape hatch for endpoints or parameters the other commands don't
wrap. `<path>` is relative to `/api/v1`; a leading `/` is added if you
omit it. `--param` is repeatable.

| Flag | Description |
| --- | --- |
| `--param` | Query parameter as `key=value` (repeatable) |

```bash
horton api /search --param q=vacuum --param limit=5
```

<Aside type="note">
  `api` always prints JSON — there's no table view, since the response
  shape is unknown to the client.
</Aside>
